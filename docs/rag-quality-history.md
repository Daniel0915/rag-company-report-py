## 삼성전자 32문항 비교

각 경로를 한 번씩 실행했으며 Claude Opus가 답변과 거절의 적절성을 채점했습니다. 정확한 섹션 적중은 접수번호·원본 파일·섹션 순번이 모두 일치하는 경우입니다.

| 지표 | Sonnet 고정 | Sonnet 에이전트 | DeepSeek 고정 |
| --- | ---: | ---: | ---: |
| 정답 | 11/24 | 12/24 | 10/24 |
| 적절한 거절 | 8/8 | 8/8 | 8/8 |
| 평균 근거 충실도 | 0.842 | 0.885 | 0.836 |
| 정확한 섹션 적중 | 9/24 | 12/22 | 9/24 |
| 실행 실패 | 0/32 | 2/32 | 0/32 |

Sonnet 에이전트는 더 많은 문항에서 정확한 섹션을 찾았지만 정답은 1개 늘었습니다. 향상 폭은 각 경로 1회 실행에서 관측한 값입니다. 고정 경로에서 Sonnet 오답 13개 중 9개, DeepSeek 오답 14개 중 9개는 해당 공시 섹션과 섹션 제목을 모두 찾지 못한 경우였습니다. 이 결과를 바탕으로 키워드 검색 병행, 검색 결과 재순위화, 보고서 기간 필터를 다음 검증 후보로 남겼습니다.

로컬 `eval/runs/`의 기준선은 `20261121-003144_local_k6.json`과 `20261121-011143_local_k6.json`에 있습니다. 로컬 경로 비교는 `20261125-001521_local_k6.json`과 `20261125-003959_local_k6_agent.json`을 사용했습니다. 32문항 비교는 `20261125-165921_claude_k6.json`, `20261125-165925_claude_k6_agent.json`, `20261125-190101_deepseek_k6.json`에, 52문항의 부분 실행은 `20261125-190949_deepseek_k6_agent.json`에 남아 있습니다.
